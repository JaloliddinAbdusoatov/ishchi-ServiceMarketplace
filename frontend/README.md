# ISHCHI frontend

Start the backend on port 8001, then run from this directory:

```powershell
npm run dev
```

Open http://127.0.0.1:5173. Vite proxies `/api/` and `/media/` to the local backend.

Run `npm test` for component tests or `npm run build` to recreate `dist/`.
See [configuration and release instructions](../PRODUCTION_MVP.md).
